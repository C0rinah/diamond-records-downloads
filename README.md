# Diamond Records PC downloads

Public playtest downloads for friends and playtesters. Download the setup program
or portable client from [the latest release](https://github.com/C0rinah/diamond-records-downloads/releases/latest).

Start the game, then continue from the title screen. The game asks before
downloading the game data. Future compatible data updates use the same process.
For a required client update, check Discord and download the new setup/client.

This repository contains download metadata and release packages. Development is
local; the private source repository is separate. These are public playtest
builds, with focused validation rather than full release qualification.

For Steam Deck, use the portable ZIP and add DiamondRecordsPC.exe to Steam as a
non-Steam game with Proton. Extract the entire ZIP before launching the game.
